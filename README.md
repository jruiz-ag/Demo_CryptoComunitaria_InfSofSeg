# Sistema Municipal de Criptoactivos

## 🚀 Descripción
Este proyecto es el trabajo de Demo Final de **Crypto Comunitaria**. Permite simular una red distribuida donde ciudadanos, comercios y el estado interactúan mediante una moneda digital local, permitiendo visualizar transacciones, balances y auditorías en tiempo real. Además de controlar penalizaciones por falta de actividad en tiempo real.

## 🛠️ Tecnologías utilizadas
* **Backend:** Python con [Flask](https://flask.palletsprojects.com/).
* **Base de datos:** SQLite (para persistencia de transacciones).
* **Frontend:** HTML5, CSS3 (con diseño basado en interacciones) y Jinja2.
* **Entorno:** Diseñado para despliegue rápido en servidores como PythonAnywhere.

## 🔑 Funcionalidades
- **Sistema de autenticación simple:** Simulación de diferentes roles (Ciudadano, Comercio, Estado).
- **Ledger en vivo:** Visualización en tiempo real de los movimientos en la red.
- **Gestión de Criptoactivos:** Transferencias, validación de saldos y bonificaciones.
- **Modo Demostración:** Botón de reinicio para restaurar el estado inicial de la base de datos para presentaciones.
